# Guía: Cambiar de usuario de GitHub en una sola computadora

El repositorio es: PabloRiveraM/Proyecto_Final---Programacion

Cuando alguien va a trabajar, ejecuta los 3 comandos de su sección.
Luego trabaja normalmente (git add, git commit, git push).

===========================================================================
 PABLO (Autor principal)
===========================================================================
git remote set-url origin git@github-pablo:PabloRiveraM/Proyecto_Final---Programacion.git
git config user.name "PabloRiveraM"

===========================================================================
 FLUJO COMPLETO de trabajo
===========================================================================
1. Ejecutar los 3 comandos de tu seccion (arriba)
2. Verificar con: git remote -v  y  git config user.name
3. Hacer tus cambios en el codigo
4. git add .
5. git commit -m "descripcion del cambio"
6. git push origin main   (o el branch que corresponda)
